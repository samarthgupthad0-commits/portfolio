## 🌐 Deploy to GitHub Pages for Free (1-Minute Guide)

1. Create a repository on GitHub (e.g. `portfolio` or `samarthguptha.github.io`).
2. Run these commands in your portfolio folder:
   ```bash
   git init
   git add .
   git commit -m "Launch Samarth Guptha D portfolio"
   git branch -M main
   git remote add origin https://github.com/samarthgupthad0-commits/<your-repo-name>.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings > Pages** &rarr; Select `main` branch / `root` folder &rarr; Save.
4. Your website will be live across the web!
